参数处理:
返回普通对象或 { params: {...} } 时继续执行 SQL。
返回 { directReturn: true, data: ... } 时跳过 SQL 和结果集处理，直接返回 data。
留空时不处理参数，直接继续执行 SQL。

直接返回示例:
async function main({ params }) {
  if (params.skipSql === true) {
    return { directReturn: true, data: { code: 0, params } };
  }
  return { params };
}

结果集处理:
SQL 执行后运行，main 的返回值就是动态 API 响应体。
直接 return resultSets 时，接口返回全部结果集。

文件能力:
勾选脚本能力后可使用 await files.inspectUrl(url) 或 await files.downloadTemp(url)。
需要自己处理异常时，可使用 files.tryInspectUrl(url) 或 callApi.tryGet(path, params)。
